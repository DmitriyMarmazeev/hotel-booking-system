# Hotel Booking System

Система управления бронированием номеров в отелях, разработанная в рамках курсовой работы по бэкенд-разработке.  
Проект состоит из серверной части на FastAPI и клиентского одностраничного приложения на Vue.js.

## 🚀 Возможности

**Для пользователей:**
- Регистрация и аутентификация
- Поиск отелей по городу, датам, количеству гостей и диапазону цен
- Просмотр детальной информации об отеле, фотографий и удобств
- Проверка доступности номеров на выбранные даты
- Бронирование номера с расчётом стоимости
- Просмотр истории своих бронирований, отмена до заезда

**Для менеджеров отелей:**
- Создание и редактирование отелей, номеров, типов номеров
- Управление бронированиями: подтверждение, отмена, завершение
- Настройка тарифов и ценовых периодов

**Для администраторов:**
- Полный доступ ко всем отелям, номерам и бронированиям
- Дашборд занятости и отчёты по выручке

## 🛠️ Технологический стек

| Компонент          | Технология                          |
|--------------------|-------------------------------------|
| Язык бэкенда       | Python 3.11+                        |
| Серверный фреймворк| FastAPI                             |
| База данных        | PostgreSQL (с JSONB для гибких полей) |
| ORM                | SQLAlchemy                          |
| Аутентификация     | JWT-токены                          |
| Документация API   | OpenAPI (Swagger UI / ReDoc)        |
| Клиентский фреймворк | Vue.js 3 (Composition API, Pinia, Vue Router) |
| Архитектура        | Модульный монолит                   |

## ⚙️ Локальный запуск

### Требования
- Python 3.11+
- Node.js 18+
- PostgreSQL 15+

### Бэкенд

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DmitriyMarmazeev/hotel-booking-system.git
   cd hotel-booking-system/backend```
2. Создайте и активируйте виртуальное окружение, установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   pip install -r requirements.txt```
3. Создайте базу данных PostgreSQL и настройте переменные окружения (пример):
   ```bash
   export DATABASE_URL=postgresql://user:password@localhost:5432/hotel_db
   export SECRET_KEY=ваш-секретный-ключ```
4. Запустите сервер:
   ```uvicorn app.main:app --reload```

Документация API будет доступна по адресу http://127.0.0.1:8000/docs.

### Фронтенд

1. Перейдите в папку фронтенда:
   ```cd ../frontend```
2. Установите зависимости и запустите dev-сервер:
   ```bash
   npm install
   npm run dev
   ```

Клиент откроется на http://localhost:5173.
Убедитесь, что бэкенд уже запущен.
